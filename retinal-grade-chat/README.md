# GitHub Pages frontend

Static HTML, CSS and JavaScript. config.js selects the HTTPS FastAPI backend. No secrets belong in this folder. The current Cloudflare Quick Tunnel is temporary and requires the existing backend server to remain running. If unavailable, the interface reports the failure and does not fabricate answers. Image uploads use the real server-held ResNet-152/X1–X4 prediction. The five optional example contexts remain illustrative. The raw file is sent as a JPG/PNG HTTP body; progress is polled asynchronously. The chat receives only the server-issued prediction identifier.

The evidence section displays nine maps/charts, four stream cards, complete measured-feature tables, a JSON download, and primary-paper references. X2 weak proxies and added true Grad-CAM are labeled separately. X3 unavailable lesion detections are never rendered as negative findings. The Open in Colab link points to the separate notebook source package; users must supply the large model bundle.
